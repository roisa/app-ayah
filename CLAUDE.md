# Mo Games — notes for Claude

## Baby Mo colour code (brand colours)
Use these for anything branded "Baby Mo" / Mo Games:

| Name   | Hex       |
|--------|-----------|
| Green  | `#00aa0c` |
| Orange | `#ff6a00` |
| Yellow | `#ffff01` |
| White  | `#fff8ee` |

In Mo Archery they are CSS variables `--moG`, `--moO`, `--moY`, `--moW` in `MoArchery/index.html`.
